# MySQL Naming Conventions Guide

This repository hosts a step-by-step guide that explains how to name MySQL database objects in a way that scales for large teams. The material is organised as standalone chapters so readers can move between topics just like browsing a W3Schools tutorial.

## How to Navigate

1. Start with the [documentation index](docs/index.md). It contains the complete table of contents and links to every published chapter.
2. Read one chapter at a time. Each chapter focuses on a single topic and explains the rule, the problems it prevents, and practical examples.
3. Revisit chapters as needed. They are written in simple English so engineers, analysts, and reviewers share the same understanding.

> _Note_: The first three chapters are ready today. Additional chapters will be published in future commits so that each addition can be reviewed carefully.
